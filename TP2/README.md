# ESR-TP2
Trabalho prático de ESR em Python


## 1º Ligar o Bootstrapper
```py 
python3 bootstrapper.py ./FilesInfo/bootstrapper.json ./FilesInfo/servidores.json ./FilesInfo/acess_point.json
```

## 2º Ligar o Servidor
```py
python3 servidor.py ./videos/
```

## 3º Ligar os nodos intermédios
```py
python3 forwarding.py
```

## 4º Ligar os Pontos de Acesso
```py
python3 pontoAcesso.py
```

## 5º Ligar o cliente
```py
python3 cliente.py <node do vídeo>
```
